### 🛒 AgentCart — The Trust Layer for AI Shopping Agents

An AI-powered shopping application designed to make agent-driven purchases safer through user-defined spending controls and human oversight.

**Key Features:**
- AI-powered shopping intent interpretation using Groq and Google Gemini.
- Product discovery through Channel3 API.
- Customizable spending limits and policy-based purchase decisions.
- Human-in-the-loop purchase approval workflow.
- PayPal Sandbox integration for order creation and payment capture.
- Transaction history and persistent storage using Turso.

**Tech:** JavaScript, React, Vite, Node.js, Express.js, Groq, Gemini, Channel3, PayPal APIs, Turso.
